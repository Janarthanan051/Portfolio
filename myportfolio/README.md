# Portfolio - Janarthanan M

A modern, responsive developer portfolio showcasing projects, skills, experience, and education. Built with HTML5, CSS3, and vanilla JavaScript.

## ✨ Features

- **Responsive Design** - Fully responsive layout that works on all devices
- **Dark/Light Theme Toggle** - User-selectable dark and light mode
- **Modern UI** - Glass-morphism cards, smooth animations, and gradient backgrounds
- **Smooth Scrolling** - Elegant scroll behavior for better UX
- **Performance Optimized** - Lightweight and fast loading
- **Accessible** - Semantic HTML and proper ARIA labels

## 🛠️ How to Use

### Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/Janarthanan051/Portfolio.git
   cd Portfolio/myportfolio
   ```

2. Open `index.html` in your browser or use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve
   ```

3. Visit `http://localhost:8000`

### Customize
- Edit `index.html` to update content (name, bio, projects, skills)
- Modify `style.css` to change colors, fonts, and styling
- Replace `janaimg.jpeg` with your own profile photo
- Update `resume.pdf` with your latest resume

## 🚀 Deployment

### Deploy on Vercel
1. Push this repository to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import your GitHub repository
4. Click "Deploy"

That's it! Vercel will automatically deploy and redeploy on every push.

### Deploy on GitHub Pages
1. In repository settings, enable GitHub Pages
2. Select main branch as source
3. Your site will be live at `https://username.github.io/Portfolio`
